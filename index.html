Minecraft Java launcher for Windows

MONO.

A black and white Minecraft launcher with animated backgrounds. Search and install mods, resource packs and shaders from Modrinth without leaving it.

Install in four steps

  1. 1. Unzip itRight-click the zip, choose Extract All, and put the folder somewhere permanent such as Documents.
  2. 2. Run Start-MONO.batThe first run downloads what it needs and takes a minute or two. After that it opens straight away.
  3. 3. Sign in with MicrosoftUse the account that owns Minecraft Java Edition. The login is encrypted by Windows and stays on your computer.
  4. 4. Add it to your Start menuClose MONO, then run Add-MONO-to-Apps.bat once. Press the Windows key and type MONO to open it, or pin it to the taskbar.

What is inside

Mods, packs and shadersBrowse Modrinth, install in one click, and see which ones you already have.
Fabric, Forge, OptiFinePick a loader on the Play page. Java is downloaded for you if it is missing.
FPS boost modsInstalls Sodium, Lithium, FerriteCore and friends for your version in one button.
Installed pageSearch, page through, import your own files, and check for updates.
Server statusLive player counts and ping. Join a server straight from the list.
World backupsAutomatic backup before each launch, with restore.
Crash doctorReads a crash report and tells you the likely cause.
11 themesMono by default, plus animated cherry blossom, embers, snow, stars and more.
Quick commandsPress Ctrl+K anywhere. Export your whole setup as a .monopack file.
